# 日志分析 - v3.1 版本问题

## 观察到的现象
1. 10:15:37 PM 收到一个 POST /webhook 请求，返回 200
2. 但是没有看到任何我添加的调试日志输出（如 "Received webhook update", "Processing update_id" 等）
3. 这说明 print 语句的输出没有显示在 Render 日志中

## 问题分析
1. Flask 的 print 输出可能没有被正确捕获到 Render 日志
2. 需要使用 logging 模块而不是 print
3. 或者需要设置 PYTHONUNBUFFERED=1 环境变量

## 解决方案
1. 使用 Python logging 模块替代 print
2. 设置 sys.stdout.flush() 强制刷新输出
3. 或者在 Render 环境变量中添加 PYTHONUNBUFFERED=1
